# Movie Ticket Booking System

A single-screen movie ticket booking website.

- Backend: Java (built-in HttpServer)
- Frontend: HTML, CSS, JavaScript

## Features
- 4 show times, 8 x 10 seat map
- Seat selection with live availability
- Double-booking prevention
- Ticket confirmation with unique ID
- Find or cancel a booking

## How to run
1. Install JDK 17 or newer
2. In the project folder run:
   javac MovieBookingServer.java
   java MovieBookingServer
3. Open http://localhost:8080
